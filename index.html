Hermes agent

A private assistant that works with its owner's Google mail, calendar and files.

What it is

Hermes agent is a personal automation tool run by one person on a computer at home. It is not a public service: nobody else can sign up for it or use it, and it is not offered for sale.

What it does with a Google account

The owner connects a Google account that belongs to them. With the owner's permission the assistant can:

  • read mail the owner forwards to that account, and file notes and tasks from it;
  • read and create calendar events, so that plans and trips appear in the owner's calendar;
  • read and save files in Google Drive that the owner asks it to work with.

It acts only on the owner's instructions and only within the accounts the owner has connected.
